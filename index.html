Lessons How it works
Static HTML · CSS · JS only — no framework, no backend

One page. One broken metric. Every time.

Every lesson below is a self-contained landing page with identical design — nav, hero, cards, gallery, footer — and exactly one deliberately exaggerated performance problem. Run Lighthouse or PageSpeed Insights on each one, watch the warnings appear, then go read the code to see precisely what caused them.

Building past the original 20 into an expanded curriculum that also covers what Lighthouse doesn't score directly — things you only see in Chrome DevTools' Performance panel: loading priority, the rendering pipeline, GPU vs. CPU work, long tasks, memory leaks, caching, compression, and more.

Building one lesson at a time — currently 1 of 30+ live.

How to use this lab

Read the code, then run the tools

Every lesson's intentional issue is wrapped in matching HTML comments marking where it starts and ends, so you can find it without guessing. Deploy the folder as-is to GitHub Pages or Cloudflare Pages — there's no backend and nothing to build. Run each page through Lighthouse in Chrome DevTools (or PageSpeed Insights once it's public) and compare the warnings you see against the metrics tag on each lesson card above.
